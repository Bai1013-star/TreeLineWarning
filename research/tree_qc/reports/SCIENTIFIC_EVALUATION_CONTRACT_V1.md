# Scientific evaluation contract V1

Frozen before any public samples or scores. Supervisor-authored supplement to RESEARCH_PLAN_V1.

Primary target y=1 REVIEW_REQUIRED, y=0 correct GT membership. For binary evaluation, score >= t is REVIEW. BAD_RECALL=TP/(TP+FN), BAD_FALSE_PASS_RATE=FN/(TP+FN), GOOD_FALSE_REVIEW_RATE=FP/(TN+FP), BALANCED_ACCURACY=(TPR+TNR)/2, F1_REVIEW=2TP/(2TP+FP+FN). Undefined denominators are null, never zero or silently excluded. Report integer confusion counts, sample counts and unique tree counts. Repeated corruptions of a tree are clustered observations, not independent trees.

Primary threshold selection: training-site validation only. Among candidate thresholds from distinct validation scores plus endpoint sentinels, choose thresholds satisfying recall>=.85 and good false review<=.25; maximize balanced accuracy, ties use smaller threshold. If none qualify, report validation target failure and select max balanced accuracy for diagnostic reporting only. Never pretend diagnostic threshold meets calibration requirements. Freeze threshold, model, split, sampler, generator and config hashes before held-out evaluation.

Optional ternary thresholds are additional outputs, never substitutions for the primary threshold. Unless a validation-only abstention rule is specified and frozen before held-out access, disable abstention (UNCERTAIN_RATE=0). If enabled, report status counts by true class and REVIEW-only recall separately from REVIEW+UNCERTAIN safety coverage. No all-uncertain success.

Public split: designate one entire site training, other entirely held out. Training/validation are spatial groups with disjoint real tree identity and context pools. Trees spanning boundary or neighbor zones crossing groups are assigned as a connected identity/context component, quarantined or kept entirely in one pool. Reject split if viable independent validation cannot be formed. Dedup must not compare only raw instance ID; global geometry overlap is mandatory. Preserve source provenance for all points. Dataset audit can inspect schema/geometry availability on either site, but held-out samples, labels and scores cannot guide generator/model design.

Default seed candidates: 1729, 2718, 3141; same training budgets/config for all final replicates. Primary train-site validation selects model family/config before opening any held-out result. Held-out tests are run as a single frozen evaluation package, including generator holdouts, seeds and 4096/2048 sampling. Reverse direction optional only if independently predeclared and fits measured resource budget; results must not tune first direction.

Scientific synthetic labels require explicit nontrivial membership error. Every corruption records realized added/removed candidate fractions and connected geometric region; a failed neighbor or stem selection cannot silently produce a mislabeled unchanged tree. Do not make class-specific padding count, sampling randomness, tensor order or point density a deterministic shortcut. Candidate/context representation and normalization shared across GOOD/BAD. Different corruptions on same identity must stay within its assigned split. Realism gate reviews training-site generated examples with geometry and realized membership changes; thresholds and public targets never change to accommodate poor results.

Gate F targets apply to moderate/high defects; mild and withheld severity reported separately. Report each requested defect even if unavailable, with unavailable reason, rather than substitute aggregate success. MERGED/CONTAMINATION/OVERSEG each require enough valid distinct tree support and better-than-trivial balanced classification; no overall PASS masking a collapsed core class. Site-level n=1 held out remains a pilot, not a population generalization claim.

Training cost guard: collect first epoch timing and projected total before full run. Bounded pilot uses validation early stopping and fixed maximum budget agreed by supervisor before run. Do not expand epochs after seeing held-out failure. Multiple seeds are performed only if cost reasonable; otherwise limitation remains explicit and cannot claim repeatability gate passed.
