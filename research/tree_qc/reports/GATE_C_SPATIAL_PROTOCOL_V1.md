# Gate C spatial protocol V1 — prospective, before examples/training

Supervisor design; not a Gate C PASS. Original evaluation targets and public protocol prefreeze remain controlling. Litchfield is training site; Wytham is held out. No model outputs, generated examples or challenge geometries have been inspected.

Canonical source groups are site-scoped full sorted float32 coordinate hash plus point count, requiring agreeing basename and available native instance ID for alias collapse. Retain all original files/native dtypes and prefer the highest-precision representative. This conservatively groups exported coordinate-equivalent sources; it does not claim biological identity beyond publisher GT. Cross-name partial overlaps and conflicting sample/ID relations require explicit checks and quarantine, not automatic unions. Full source hashes, bboxes, centroids, point counts and fingerprints must remain in the manifest.

For Litchfield, fixed geometric split: x boundary at the70th percentile index floor(.7*(n-1)) of all canonical source centroids before eligibility filtering. Current canonical703sources yield67.92401220579217m. Do not move the boundary to optimize yield or model performance. Assign a whole source to train only if bbox_xmax+3m < boundary, to validation only if bbox_xmin-3m > boundary; all others quarantine. Preliminary442train/177validation counts are before correspondence/neighbor exclusions, not accepted counts.

Use real neighboring tree files as local context, preserving publisher coordinates before a shared candidate-derived translation. Local query is candidateXYbbox expanded3m. Source candidates and donors must belong to one spatial pool; a merged candidate union must also retain query containment in that pool. Context membership includes only actual neighboring source points within the query. No invented context, unrelated donor, worldXY feature, RGB or hidden scalar. Plot ground/background is not included in this first tree-context implementation; background source pool is explicitly empty, not asserted complete plot context.

Apply the same correspondence eligibility rule to both sites: unresolved canonical sources, conflicting exact-sample IDs, and unverified coordinate-frame relations are unavailable as candidate and donor/context. Exclude candidate queries intersecting unresolved/quarantined source bboxes, so omitted boundary trees do not silently form different context. Require actual nonempty neighboring source geometry; bbox proximity alone cannot fabricate points. Eight-point correspondence is supporting evidence, not full membership proof; unresolved cases remain unresolved and coverage loss is reported, never used to redesign held-out eligibility.

Before Gate C PASS, verify exact aliases plus cross-group overlap/ID evidence, pointwise plot semantic/instance consistency, actual common metric frame, and frozen manifest assertions. Candidate root IDs, context/donor root IDs and all underlying source-file aliases must be disjoint across train/validation/test; source point provenance must be retained. The fixed split and maximum query extent must prevent shared point pools even when a candidate is modified. No generator or training may proceed before independent review and Supervisor acceptance. If independent support falls below the predeclared minimum, report insufficiency; do not move boundaries or mix sites to manufacture support.
