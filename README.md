# TreeLineWarning 树线智能巡检

当前整理版本：**2026/10/22**。Windows 离线桌面软件，用于 LAS/LAZ 点云处理、树木与导线净空分析、树木生长情景预测及预警工单生成。除主动连接气象服务外，主要处理和查看功能在本机运行。

## 基本流程

1. 新建项目并选择保存位置，导入原始 LAS/LAZ，确认单位与坐标信息。
2. 按线路顺序选择杆塔并生成档距，执行点云处理与导线拟合。
3. 查看单木结果，进行合并、分开或区域剔除；杆线保护对象与树木编辑对象分开处理。
4. 在原始点云中查看树干和 1.30 m 胸径截面，核对测量结果。无可靠结果时保留缺失状态，不能用假值代替。
5. 在“查看数据”中导出；短时预测可直接读取项目结果或人工填写，并按每棵树确认树种、树龄及测量值。
6. 选择短时 1–15 天并逐日填写天气，或使用长时表格预测和月平均气象情景。
7. 查看净空、风险等级和工单，选择保存位置导出。

天气历史支持命名保存、一键导入与再次编辑。“风偏”指受风横向位移，不是风的级别；风力等级和位移分别显示。

## 开发与验证

建议 Python 3.11。开发依赖可通过 `python -m pip install -e ".[dev,desktop]"` 安装；点云全流程还需要匹配 ABI 的 PDAL、GDAL、PROJ 原生运行库，Windows 窗口需要 WebView2。单独安装 Python 依赖不等于完整离线运行环境。完整可运行环境以发布包为准。

从源码目录启动集成桌面入口：

```powershell
python -m desktop.app
```

大型树种识别权重 `data/bioclip/bioclip_image_encoder.onnx` 不纳入普通 Git，使用便携包中同路径文件；无需权重的核心回归测试仍可运行：

```powershell
python -m pytest -q -p no:cacheprovider tests/test_weather_templates_daily_scope.py tests/test_three_four_wires.py tests/prediction/test_daily_weather.py
```

浏览器脚本在 `tests/ui/`，需要 Playwright、Edge 及本机测试服务，相关路径通过脚本参数或环境变量指定。部分历史现场验收脚本仍使用原测试机路径，不是跨机器自动验收入口。

本次已记录 31 项定向回归通过、逐日天气历史导入及编辑、1/3/7/15 天风险表和工单、真实点云三根同高度导线的检查结果。见 [验收摘要](docs/releases/acceptance-20261022.json)。这不是“所有按钮排列组合”的穷举证明，也不代表在所有点云上的测量精度已得到独立验证。
