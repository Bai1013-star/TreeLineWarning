# 胸径复核：等待实际树干身份确认

本次仍为 **12 棵树、7 个已恢复胸径、5 棵待人工确认**。原有 7 个数值未改变。
V4 没有重建 EXE，旧 ZIP 不包含此工作流。以下操作用于当前开发机上的源码应用。

在仓库目录运行：

```powershell
Set-Location 'E:\TreeLineWarning-fast'
& '.\.venv311\Scripts\python.exe' -B -m desktop.app --project-root 'E:\2026.8.31-2\2026.08.31-2\2026.08.31-2'
```

也可双击 `acceptance_evidence/dbh_recovery_v4_20260831/OPEN_DBH_REVIEW.cmd`。
这会使用现有原生桌面窗口，不会重新运行完整点云分析。

1. 打开当前项目的 **单木结果查看与复核 / Tree Review**，点击 **胸径复核 / DBH Review**。
2. 在左侧选择待复核树，点击 **准备点云复核**。首次恢复项目可能需稍等。
3. 对 T-1-006、T-1-007、T-1-009，分别查看 3、2、2 条候选轴。旋转、缩放，对照当前树冠和低位树干；点击确属该树的候选，观察高亮。分数不是概率，最高分不等于正确答案。
4. 对 T-1-001、T-1-011，点击 **点击树干**，再点击可见的原始树干点。界面显示精确源点索引；蓝色树冠背景不能充当种子。
5. 只有确认树干身份后，勾选身份确认框，再点击计算/确认按钮。**不要把算法生成的候选当成人已确认的结果。** 无法判断时保留未确认。
6. 系统计算胸径。几何不合格仍显示不可用，不会用人工输入或估算填空。成功时来源为 **人工确认点云**。
7. 查看当前报告；按现有导出操作生成 Survey / Prediction_Input。关闭、重新打开项目，核对确认结果。随后将实际选择和结果交回验收。

如果树又被删除、局部剔除、合并、撤销或重新定稿，旧复核会失效，必须重新打开当前版本的复核。
提交超时或状态不明时不要反复点击提交；先重新打开项目核对状态。

五棵树的会话路径、候选 ID、哈希和展示点数见
`acceptance_evidence/dbh_recovery_v4_20260831/review_ready.json`。
准备过程没有做任何真实树干选择，也没有计算新的真实胸径。
