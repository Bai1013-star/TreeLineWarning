# 树线安全距离分析与主动预警系统——最终需求文档

> 版本：v2.3（八月底交付版）  
> 更新日期：2026-07-20  
> 计划截止日期：2026-08-31  
> 项目根目录：`E:\TreeLineWarning`

## 1. 项目定位

本项目面向手持三维激光扫描设备采集的输电线路走廊 LAS 点云，完成：

```text
点云导入
→ 文件头与质量检查
→ 分块读取、裁剪、去噪和降采样
→ 自动/半自动语义分类
→ 多根导线实例分离与曲线重建
→ 单木实例分割
→ 当前树线净距计算
→ 风险分级
→ 未来危险时间预测
→ 三维结果展示
→ Word / Excel 报告
```

八月底交付目标是“可稳定演示的半自动版本”，不承诺任意场景完全自动、无限规模点云加载或工程级绝对预测精度。

用户和队友统一视为一个“项目组”。项目组内部由谁负责哪项工作，由用户自行安排，本文档不固定个人分工。

## 4. 第一阶段：LAS 读取、检查与裁剪

### 4.1 文件头读取

必须使用只读方式读取 LAS 文件头，至少输出：

- 文件路径和文件大小；
- LAS 版本；
- Point Format；
- 点数；
- XYZ 最小值和最大值；
- Scale 与 Offset；
- 标准维度和 Extra Bytes；
- 是否有 RGB；
- 是否有强度；
- 是否已有 classification 字段；
- 估算完整读取所需内存。

读取文件头时不得加载全部点。

### 4.2 分块读取

大文件必须采用分块迭代方式，要求：

- 分块点数可配置；
- 默认从较保守值开始；
- 每块处理后释放不再需要的数组；
- 显示进度、已处理点数和异常；
- 不在内存中同时保留多份完整点云；
- 保留原始点索引或稳定的来源标识。

### 4.3 裁剪

支持：

- 按 XYZ 包围盒裁剪；
- 根据文件头范围辅助选择区域；
- 裁剪结果保留原 LAS Point Format、Scale、Offset 和必要维度；
- 输出新的 LAS 文件；
- 原文件只读；
- 同名文件不得静默覆盖；
- 生成裁剪记录，包括来源文件、范围、点数、时间和输出路径。

第一轮允许先通过坐标输入裁剪，三维交互框选可后续增加。

## 5. 点云预处理

至少实现：

- 局部坐标原点转换；
- NaN、无穷值和异常坐标检查；
- 统计离群点去除；
- 体素降采样；
- 空间分块和重叠块；
- 法向量估计；
- 线性度、平面度、散乱度和垂直度；
- SMRF 或等价方法辅助地面提取；
- 离地高度 HAG；
- 中间结果保存和重新加载。

同时保留：

```text
原始高密度点：最终距离计算
降采样点：分类、聚类、拟合和显示
```

## 6. 语义分类路线

### 6.1 六类标签

| 标签 | 类别 |
|---:|---|
| 0 | 其他 |
| 1 | 地面 |
| 2 | 建筑及人工构筑物 |
| 3 | 电力线 |
| 4 | 树干 |
| 5 | 树枝与树冠 |

每个点至少输出：

- `semantic_label`；
- `semantic_confidence`；
- `source`：`rule`、`model` 或 `manual`；
- `original_index` 或等价来源标识。

### 6.2 八月底版本的模型选择

正式轻量语义模型优先使用：

```text
Open3D-ML RandLA-Net（PyTorch）
```

使用方式：

1. 第一阶段不依赖模型，先用规则、人工选择或模拟标签跑通闭环；
2. 基础闭环通过后，在独立 `treeline-ml` 环境中接入 RandLA-Net；
3. 公开预训练权重只作为初始化或快速验证，不能直接当作项目最终模型；
4. 使用项目组自己的手持点云进行少量六类标注和微调；
5. 电力线和树干属于少数类，训练时支持类别权重或 Focal Loss；
6. 采用分块训练和推理，默认 `batch_size=1`、AMP；
7. 模型失败或权重缺失时，系统自动回退到规则/人工模式。

PointNeXt-S 保留为后续对照或升级方案，不在八月底前同时维护两套正式模型。

语义模型只回答“这个点是什么”，不负责自动编号第几根导线或第几棵树。

## 7. 多根导线实例分离与重建

输入：语义分类或人工选择得到的电力线候选点。

流程：

```text
线性特征筛选
→ PCA 估计线路总体方向
→ 建立沿线局部坐标
→ 沿线路方向切片
→ 截面内聚类
→ 跨切片轨迹关联
→ 生成独立 wire_id
→ 三次 B 样条拟合
→ 高密度曲线采样
```

至少输出：

- `wire_id`；
- 导线点或中心轨迹；
- B 样条参数；
- 拟合误差；
- 覆盖率；
- 置信度；
- 失败原因。

第一版测试至少覆盖：

- 三根平行弯曲导线；
- 高低错层导线；
- 局部缺点；
- 短距离断裂；
- 少量离群点。

## 8. 单木实例分割

第一版首选：

```text
pointtree 工具包中的 TreeXAlgorithm
```

输入尽量只包含地面和植被点，并提前去除建筑、电线、车辆和其他人工目标。

输出：

- 每点 `tree_id`；
- 树干位置；
- 树高；
- 树冠范围；
- 未分配植被；
- 分割来源；
- 置信度或质量标记。

降级方案：

```text
自动或人工树干种子
→ 体素/超体素图
→ 多源区域生长
→ 人工拆分、合并和重新分配
```

不得把一次全局 DBSCAN 直接作为最终单木分割方法。

## 9. 当前树线净距与风险

每棵树至少计算：

- 最短三维距离；
- 最短水平距离；
- 垂直净空；
- 最近树木点；
- 最近导线点；
- 最近 `wire_id`；
- 当前风险等级。

方法：

```text
原始高密度树木点
＋ 高密度采样导线曲线
＋ 包围盒粗筛
＋ KD-Tree 局部精确查询
```

必须保存最近点对，以便在界面中显示距离连线。

风险等级：

- 绿色：安全；
- 黄色：关注；
- 橙色：预警；
- 红色：危险；
- 灰色：数据或算法质量不足，需人工复核。

阈值全部配置化，结果记录阈值版本。

## 10. 未来危险时间预测

第一版采用可解释的情景线性预测，不强制使用 LSTM。

输入：

- 当前净距；
- 关注、预警和危险阈值；
- 树冠朝导线方向的年增长速度；
- 扫描日期；
- 最大预测年限。

输出：

- 乐观、常规、保守三档情景；
- 预计进入关注日期；
- 预计进入预警日期；
- 预计进入危险日期；
- 生长率来源；
- 预测置信度；
- 建议复测日期。

必须显示：

```text
基于设定生长率或有限历史数据的辅助预测，不作为绝对工程结论。
```

第二阶段再支持多时相点云配准、同树匹配、历史净距、稳健回归和置信区间。

## 15. 第一版完成定义

第一版必须能稳定完成：

```text
打开或新建工程
→ 读取原始LAS文件头
→ 从较小LAS分块裁剪测试样本
→ 预处理并显示点云
→ 通过规则/人工/模型获得语义类别
→ 分离并拟合多根导线
→ 使用TreeX或降级方案分出单木

→ 显示最近点对和趋势图
→ 导出Excel和Word
→ 保存并重新打开工程
```

八月底验收标准：至少一个简单真实场景效果较好，另外两个场景能够运行并允许人工修正；所有限制必须如实展示。
