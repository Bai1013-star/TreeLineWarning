# Finalized-only local Future Geometry Preview

The desktop Preview is separate from the current Survey report and `Prediction_Input.xlsx`. Its only implemented predictor is `LocalScenarioPredictor`: local CPU/NumPy geometry scaling for +1, +3 and +5 years. No Software B, second computer, network, downloaded model or GPU is required. Future wire geometry and future clearance are **NOT_IMPLEMENTED**.

`/future-preview.html` reads `/api/future-preview?horizon=1|3|5`. The adapter verifies the existing persisted and hydrated current-finalized gate, binds each persistent tree identity to its canonical metrics and project Span/Tower identities, and samples that same tree's authoritative final XYZ. Each tree receives a separate share of the 30,000-point display budget; Z extremes are retained. Full parent membership counts accompany the bounded display points. These points are not new current membership and carry no `original_index` output.

The adapter copies inputs into immutable predictor records. It caches only the bounded in-memory display snapshot, keyed by the project, hydrated result identity, publication/journal gate and complete editor operation content. The gate and revision are rechecked after transformation. A concurrent edit, finalize, stale run or unavailable proof returns LOCKED with no geometry. No project artifacts are written, and `final_projection(persist_display_evidence=False)` prevents display-sidecar publication. Current canonical metric values are preserved; unavailable DBH remains null/blank.

The page always displays the experimental warning. Current and future point overlays use distinct colors and retain the fitted **current** W1 curves. A lightweight gate check every three seconds clears the view if the publication changes; selecting Current also requires this check. Horizon requests clear the old view, reject stale asynchronous responses and have a finite timeout. The page never calls finalize, edit or export endpoints.

All future geometry is labelled `SYNTHETIC_FUTURE_GEOMETRY`, `EXPERIMENTAL`, `NOT_CURRENT_SURVEY_SCIENCE` and `NOT_VALIDATED_LONG_TERM_BIOLOGICAL_FORECAST`. Annual increments and missing-dimension assumptions are illustrative geometry parameters; the program claims no biological forecast accuracy. Optional future predictors can share the predictor protocol and geometry contract, but no external/model adapter is implemented in this delivery.

The analysis UI additionally forwards the independent execution policy AUTO/SERIAL/PARALLEL through existing readiness/registration checks. REAL/FIXTURE remains a separate analysis mode. Retry preserves the stored execution policy unless explicitly changed, preserves the original selected Span set, and leaves source preparation, canonical science and exact-cache behavior to the scheduler. The UI shows the actual scheduler decision and fallback reason.
